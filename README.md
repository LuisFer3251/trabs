# Trabs

Repositório de projetos e atividades acadêmicas voltados para desenvolvimento web, com foco em HTML, CSS e criação de interfaces.

## Objetivo

Praticar e consolidar conceitos de desenvolvimento front-end, incluindo estruturação de páginas, layouts, formulários, responsividade e apresentação visual.

## Stack

- HTML
- CSS
- JavaScript
- Desenvolvimento web front-end
- Design de página e experiência do usuário

## Conteúdo

- Atividades acadêmicas
- Exercícios de HTML/CSS
- Criação de interfaces web
- Prática de organização e apresentação visual

## Status

Repositório de estudo e exercícios acadêmicos em front-end.

## Tecnologias principais

- HTML5
- CSS3
- JavaScript
- Git / GitHub
